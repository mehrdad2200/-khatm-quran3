نسخهٔ دسکتاپ «ختم قرآن» (ویندوز / مک / لینوکس)

راه ساده (بدون نصب چیزی): برنامه یک PWA است.
  - ویندوز/مک با Chrome یا Edge: آدرس برنامه را باز کنید، در نوار آدرس روی آیکون «Install / نصب» بزنید.
    برنامه با پنجرهٔ مستقل، آیکون روی دسکتاپ/منوی استارت و کار آفلاین نصب می‌شود.

راه فایل نصبی (.exe / .dmg) با Electron:
  1) Node.js را نصب کنید (nodejs.org).
  2) در همین پوشه (desktop) این دستورها را بزنید:
       npm install
       npm start              (اجرای آزمایشی)
       npm run dist:win       (ساخت نصب‌کنندهٔ ویندوز؛ خروجی در desktop/dist)
       npm run dist:mac       (روی خود مک)
       npm run dist:linux
  توجه: ساخت .exe باید روی ویندوز (یا با wine) و ساخت .dmg فقط روی مک انجام شود.
  این اسکلت اینجا اجرا و تست نشده است (در محیط ساخت اینترنت نبود)؛ اگر خطایی دیدید بگویید تا درست شود.
  توجه: برخی قابلیت‌ها (اعلان، سرویس‌ورکر آفلاین) در فایل نصبی Electron با نسخهٔ PWA کمی فرق دارند.
